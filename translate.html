Help Translate Tab Space

Tab Space uses AI to prepare translation drafts and automated checks to keep every language complete. Suggestions from people who use the language are still the best way to improve wording and tone.

For developers

Each language has its own file in the locales directory. Edit one locale, run npm run i18n:check from the admin directory, and open a pull request. See the translation guide for details.

For everyone else

No GitHub account or technical knowledge is needed. In your message, please include the language, the current text, and your suggested translation. A screenshot or a short description of where the text appears is helpful.

Send translation suggestions to joyuercn@icloud.com.
