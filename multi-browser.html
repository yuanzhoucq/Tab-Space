Multi-Browser Support

Use Tab Space in Chrome, Edge, and Firefox

Tab Space is a native Mac app. Alongside Safari, it can also save and restore tabs in Google Chrome, Microsoft Edge, and Firefox. Whichever browser saves a session, the session lives in the Mac app and syncs through your own iCloud — so a workspace saved in Chrome opens again in Safari, on your iPhone, or on your iPad.

Companion browsers connect to the Mac app once, with a local pairing code. Multi-browser support is included with Tab Space Pro.

Multi-browser support is available now as a beta feature of Tab Space Pro 4.0. Because it is beta, please report anything that misbehaves to support@mytab.space — reports go straight to the developer.

What you need

  • Tab Space 4.0 or later for Mac (macOS 11 or later), launched at least once.
  • A Tab Space Pro subscription.
  • Google Chrome, Microsoft Edge, or Firefox 121 or later on the same Mac.

Step 1 — Install the extension

Firefox

Install Tab Space from Firefox Add-ons. Firefox 121 or later is required.

Chrome

Install Tab Space from the Chrome Web Store.

Microsoft Edge

Edge installs the same extension from the Chrome Web Store. Open the Chrome Web Store listing in Edge and choose Allow extensions from other stores when Edge asks, then install as usual. A separate Microsoft Edge Add-ons listing is still in review.

Step 2 — Get your pairing code

  1. Open Tab Space on your Mac.
  2. Click Multi-Browser Support… in the main window.
  3. Click Show Pairing Code. A six-digit code appears; Copy Code puts it on the clipboard.

The first time you do this, Tab Space registers a small background helper as a login item. If macOS asks for approval, enable Tab Space Helper in System Settings → General → Login Items, then show the code again. After pairing, the Mac app does not have to stay open — the helper keeps working in the background.

Step 3 — Connect the browser

  1. Click the Tab Space icon in the browser toolbar.
  2. Enter the six-digit code.

That is the whole setup. The browser can now save its open tabs into Tab Space and restore any saved session. Repeat the three steps for each additional browser: every browser gets its own pairing code, and the code changes after a browser connects.

How the connection works

  • Everything stays on your Mac. The browser talks to the Tab Space helper over the local loopback interface (127.0.0.1). No session content passes through a server run by the developer.
  • The pairing code is used once. After it is accepted, the helper issues a token that is kept in the Mac Keychain, while the browser keeps its copy in local extension storage.
  • Sessions are not stored in the browser. They live in the Mac app's database and sync with iCloud, so they survive a browser profile reset.
  • A save is confirmed by the Mac app. Tabs are only closed after the app acknowledges that the session was written.

If a browser will not connect

  • "Tab Space Helper was not detected." Open Tab Space once, then check System Settings → General → Login Items and make sure Tab Space Helper is enabled.
  • The code is rejected. Codes are single-use. Open Multi-Browser Support in the Mac app, choose New Code, and enter the fresh code.
  • Firefox forgets the extension. A temporary add-on loaded through about:debugging is removed when Firefox quits — install the signed version from Firefox Add-ons instead.
  • Still stuck? Write to support@mytab.space.

多浏览器支持

在 Chrome、Edge 和 Firefox 中使用 Tab Space

Tab Space 是一款原生 Mac App。除 Safari 外，它也可以在 Google Chrome、Microsoft Edge 和 Firefox 中保存和恢复标签页。无论由哪个浏览器保存，会话都保存在 Mac App 中，并通过你自己的 iCloud 同步——在 Chrome 中保存的工作区，可以在 Safari、iPhone 或 iPad 上重新打开。

配套浏览器只需使用本地配对码连接一次。多浏览器支持包含在 Tab Space Pro 中。

多浏览器支持现已作为 Tab Space Pro 4.0 的 Beta 功能提供。 由于仍处于 Beta 阶段，如果遇到任何问题，欢迎及时反馈至 support@mytab.space，反馈会直接到达开发者。

准备工作

  • Mac 版 Tab Space 4.0 或更新版本（macOS 11 或更新版本），并至少启动过一次。
  • Tab Space Pro 订阅。
  • 同一台 Mac 上的 Google Chrome、Microsoft Edge 或 Firefox 121 及以上版本。

第一步 — 安装扩展

Firefox

从 Firefox Add-ons 安装 Tab Space，需要 Firefox 121 或更新版本。

Chrome

从 Chrome 应用商店 安装 Tab Space。

Microsoft Edge

Edge 可以直接安装 Chrome 应用商店中的同一个扩展：在 Edge 中打开 Chrome 应用商店页面，在 Edge 提示时选择允许来自其他商店的扩展，然后照常安装即可。 Microsoft Edge 加载项商店的独立上架仍在审核中。

第二步 — 获取配对码

  1. 在 Mac 上打开 Tab Space。
  2. 在主窗口中点按多浏览器支持…。
  3. 点按显示配对码，会出现一个六位数字的配对码，拷贝配对码可以直接复制到剪贴板。

首次操作时，Tab Space 会把一个后台 Helper 注册为登录项。如果 macOS 请求确认，请在“系统设置”→“通用”→“登录项”中启用 Tab Space Helper，然后重新显示配对码。配对完成后，Mac App 不需要一直开着，Helper 会在后台继续工作。

第三步 — 连接浏览器

  1. 点按浏览器工具栏中的 Tab Space 图标。
  2. 输入六位配对码。

设置到此完成。该浏览器现在可以把打开的标签页保存到 Tab Space，也可以恢复任意已保存的会话。 每增加一个浏览器都重复这三步：每个浏览器使用各自的配对码，并且浏览器连接成功后配对码会自动更新。

连接是如何工作的

  • 所有数据都留在你的 Mac 上。浏览器通过本地回环接口（127.0.0.1）与 Tab Space Helper 通信，会话内容不会经过开发者的服务器。
  • 配对码只能使用一次。验证通过后，Helper 会签发一个令牌保存在 Mac 钥匙串中，浏览器则把自己的副本保存在扩展的本地存储里。
  • 会话不保存在浏览器中。它们保存在 Mac App 的数据库中并通过 iCloud 同步，即使浏览器配置被重置也不会丢失。
  • 保存以 Mac App 的确认为准。只有在 App 确认会话已写入后，标签页才会被关闭。

如果浏览器无法连接

  • 提示未检测到 Tab Space Helper。先打开一次 Tab Space，再到“系统设置”→“通用”→“登录项”中确认 Tab Space Helper 已启用。
  • 配对码被拒绝。配对码是一次性的。在 Mac App 中打开“多浏览器支持”，选择新配对码，再输入新的配对码。
  • Firefox 重启后扩展消失。通过 about:debugging 加载的临时附加组件会在 Firefox 退出时被移除，请改从 Firefox Add-ons 安装已签名的版本。
  • 仍然无法解决？请联系 support@mytab.space。
