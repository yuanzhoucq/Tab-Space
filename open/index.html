1 mytab.space 4
  1. 1
    Open the page menu 打开页面菜单

    In Safari, tap the page menu button at the left of the address bar.

    在 Safari 中，点地址栏左侧的页面菜单按钮。

  2. 2
    Turn on Tab Space 启用 Tab Space

    Choose Manage Extensions, switch on Tab Space, then come back to this page.

    选择“管理扩展”，打开 Tab Space，然后回到此页面。

  3. 3
    Allow it on this website 允许它访问此网站

    Open the page menu again, choose Tab Space, and always allow it on this website.

    再次打开页面菜单，选择 Tab Space，然后选择在此网站上始终允许。

  4. 4
    Reload this page 重新载入此页面

    Your tabs open right away. Each link works once, for two minutes; if it has expired, go back to Tab Space and open the session in Safari again.

    标签页会立即打开。每个链接只能使用一次，两分钟内有效；过期后请回到 Tab Space，重新在 Safari 中打开该会话。

This page has to be open in Safari: the extension does not run in other browsers.

此页面需要在 Safari 中打开，扩展无法在其他浏览器中运行。
